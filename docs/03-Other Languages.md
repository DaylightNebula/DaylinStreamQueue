# Other Languages
We want to be able to support other languages and targets other than the JVM, the target list is below.  This is to give
native systems and web systems the ability to interact with daylin-sq.

Languages:
- Rust via a cargo crate named "daylin-sq-client-rust"
- Java via a Gradle project named "daylin-sq-client-java" (rename existing client)
- JS/TS via a npm compatible package named "daylin-sq-client-js" (should contain typescript bindings)
